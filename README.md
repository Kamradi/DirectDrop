# qnid

<p align="center"><img src="assets/qnid-icon.png" width="160" alt="qnid"></p>

**Русский** | [English](README.en.md)

**qnid — новое название DirectDrop (рабочее название).** Это то же приложение с новой иконкой и сохранением совместимости устройств.

**Передавайте файлы между телефоном и компьютером — просто и напрямую.**

qnid помогает отправлять фотографии, видео, документы и другие файлы между
устройствами по локальной сети или через интернет. Файлы передаются напрямую,
без загрузки на промежуточный сервер и без регистрации в qnid.

**Все файлы при передаче через интернет защищены сквозным шифрованием WebRTC/DTLS.**
Данные шифруются на отправляющем устройстве и расшифровываются на принимающем.
Шифрование интернет-передачи включено автоматически.

**[Скачать qnid для Windows](https://github.com/Kamradi/qnid/releases/latest)**

## Для чего нужен qnid

- Перенести фотографии и видео с телефона на компьютер в исходном качестве.
- Отправить документы и другие файлы с компьютера на телефон.
- Обменяться файлами между устройствами рядом или через интернет.

## Возможности версии для Windows

- Поиск устройств в локальной сети и передача файлов в обе стороны.
- Подключение через интернет по приглашению и ответной ссылке.
- **Шифрование всех файлов при передаче через интернет** (WebRTC/DTLS) и код сверки устройств.
- Подтверждение приёма файлов, отображение прогресса и скорости передачи.
- Выбор папки сохранения и кнопка открытия папки после приёма.
- Светлая и тёмная тема вслед за настройками Windows.
- Русский, English, Français и Español; выбор языка в настройках или автоматически вслед за Windows.
- Работа в трее, уведомления и настраиваемая автозагрузка.
- Проверка и установка обновлений из самого приложения.

Для обмена с мобильным устройством нужна совместимая версия qnid.
Публичные приложения для iOS и Android пока готовятся к выпуску.

## Установка на Windows

1. Откройте [последний выпуск](https://github.com/Kamradi/qnid/releases/latest).
2. В разделе **Assets** скачайте архив **qnid-…-win-x64.zip**.
3. Распакуйте его в папку, доступную для записи, и запустите **qnid.exe**.

Устанавливать .NET отдельно не требуется. Для подключения через интернет
нужен **Microsoft Edge WebView2 Runtime**. Сборка x64 предназначена
для компьютеров с процессорами Intel/AMD.

## Язык интерфейса

В версии 0.5.0 доступны **Русский, English, Français и Español**.
Выберите язык в **Настройки → Язык интерфейса**, затем полностью выйдите
через меню значка в трее и запустите qnid снова. Крестик окна только скрывает приложение.
По умолчанию используется язык Windows; для неподдерживаемых языков — английский.

## Как передаются файлы

В локальной сети устройства находят друг друга автоматически. Для подключения
через интернет нужно обменяться приглашением и ответом, затем сравнить код сверки.

Интернет-режим использует прямое соединение и **только STUN**.
TURN и серверная пересылка файлов не используются. Некоторые сети и настройки NAT
не позволяют установить прямое соединение.

## Переход с DirectDrop (рабочее название)

Выпуск **qnid 0.6.0** продолжает развитие DirectDrop (рабочее название). В старом приложении
откройте **Настройки → Проверить обновления**: переходный пакет подписан прежним ключом.
Настройки, выбранный язык и папка сохранения сохраняются. На обновлённой установке
имя старого EXE остаётся прежним для сохранения ярлыков и автозагрузки, а само приложение
отображается как **qnid** с новой иконкой.

Для новой установки выбирайте **qnid-…-win-x64.zip** и запускайте **qnid.exe**.
Архивы **DirectDrop-…-win-x64.zip** (имя файла сохранено с рабочего названия) и метаданные `update-win-x64.json` нужны старым
обновляторам. Новый клиент использует `update-qnid-win-x64.json`.
Старые сетевые идентификаторы сохранены для совместимости; их наличие не означает,
что запущена старая версия приложения.

## Обновления

Начиная с версии 0.4.0, откройте **Настройки → Проверить обновления**.
Проверка при запуске уведомляет о новой версии; загрузка и установка выполняются
по нажатию пользователя. Перед установкой завершите передачу и отключите устройство.
Переход **0.4.0 → 0.4.1** через встроенное обновление успешно проверен на Windows.

Приложение проверяет подпись метаданных RSA-3072 и SHA-256 пакета.
Настройки и принятые файлы сохраняются. Для неудачного запуска новой версии
предусмотрен возврат предыдущего EXE; этот сценарий пока отдельно не проверялся.
Пользователи версий 0.3.x устанавливают первый выпуск с обновлениями вручную.

Сертификата Windows Authenticode пока нет: подпись обновлений проверяется
внутри qnid и не заменяет сертификат издателя Windows.
