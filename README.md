# DirectDrop для Windows

Передача файлов между Windows и iPhone по локальной сети и через интернет.

**[Скачать DirectDrop для Windows x64](https://github.com/Kamradi/DirectDrop/releases)**

Сборка 0.4.1 опубликована для проверки онлайн-обновления с 0.4.0. Полный сценарий установки на Windows ещё проверяется.
Скачайте `DirectDrop-0.4.1-win-x64.zip` из раздела Assets, распакуйте в доступную
для записи папку и запустите `DirectDrop.exe`. Устанавливать .NET отдельно не нужно.
Для режима через интернет необходим Microsoft Edge WebView2 Runtime.

## Возможности

- Отправка и приём файлов с совместимым DirectDrop iOS.
- Поиск устройств в локальной сети.
- Через интернет: прямое WebRTC-соединение с шифрованием DTLS, обмен приглашением и ответом, код сверки устройств.
- Только STUN, без TURN и серверной пересылки файлов. Некоторые сети/NAT не позволяют установить прямое соединение.
- Системная светлая и тёмная тема, трей, уведомления о подключении и запрос принятия файлов.
- Настраиваемая автозагрузка и ограничение запуска одной копией.
- Проверка обновлений через GitHub Releases; загрузка и установка по нажатию пользователя.

## Обновления

Начиная с 0.4.0, в настройках есть пункт «Проверить обновления».
Автоматическая проверка при запуске только уведомляет о новой версии.
Приложение принимает только стабильные выпуски с корректной RSA-3072 подписью
метаданных и совпадающим SHA-256 пакета. Тестовые выпуски не устанавливаются автоматически.
Для установки завершите передачу, отключите устройство и закройте остальные копии.
Программа перезапустится с прежними настройками; при неудачном запуске предусмотрено
восстановление предыдущего EXE. Онлайн-обновление заменяет EXE; свежие инструкции
также доступны в полном архиве выпуска. Пользователям 0.3.x первый переход нужно выполнить вручную.

Подпись пакета обновления — отдельная проверка внутри DirectDrop.
Сертификата Windows Authenticode пока нет; Windows может показать предупреждение SmartScreen.
В каждом выпуске публикуется SHA-256 архива. Не отключайте защиту Windows ради запуска.

Исходный код DirectDrop закрыт. Все права на DirectDrop защищены.
